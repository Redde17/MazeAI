# MazeAI

Questo progetto mira alla osservazione del funzionamento di vari algoritmi di intelligenza artificiale tramite la ricerca di un percorso all’interno
di un labirinto generato in tempo reale per permettere di osservare meglio il funzionamento dei
vari algoritmi

## Contenuti
La repository contiene tutto il necessario per mettere su un ambiente di sviluppo e compilare le build necessarie.

## Installazione
Il programma, se preso tramite release, non necessita di nessuna installazione.

##Avviare la modalità di benchmark
Per poter usufruire della modalità di benchmark è necessario scaricare e compilare il codice facendo delle piccole modifiche ai #define di interesse nel file source.cpp

## Altro
Per eventuali problemi di linking con la libreria SFML, consultare il tutorial d'introduzione della libreria: <br/>
